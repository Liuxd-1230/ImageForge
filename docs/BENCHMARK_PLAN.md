# Anima-2.9B Prompt Benchmark 对照评测计划与基准规范

## 1. 评测目标与价值

本评测旨在回答核心问题：
> **同一个用户中文画面要求，ImageForge 编译出的结构化 Prompt 是否在“忠实度、属性绑定、动作关系与成图质量”上系统性优于纯 Tag 拼贴与纯自然语言长句？**

---

## 2. 评测环境与基线条件

- **生图模型**：Anima-2.9B (1024x1536 分辨率)
- **固定采样参数**：Euler 采样器 + sgm_uniform 调度器，28 步，CFG 4.5
- **对照变体 (Variants)**：
  1. **Variant A (Tag-only Baseline)**：传统 Danbooru 纯标签扁平堆叠。
  2. **Variant B (ImageForge Structured Mixed)**：Tag 区（Safety / Count / Trigger / Artist / LoRA）+ 自然语言动作归属从句。
  3. **Variant C (NL-heavy)**：纯自然语言叙述模式。

---

## 3. 四维评分标准 (0 ~ 3 分制)

| 评分维度 | 0 分 | 1 分 (部分符合) | 2 分 (基本符合) | 3 分 (完全正确) |
| :--- | :--- | :--- | :--- | :--- |
| **忠实度 (Faithfulness)** | 出现严重脑补或缺失关键要求 | 遗漏了次要描述或出现少量未提及元素 | 表达了全部主体，无明显多余设定 | 100% 忠实于用户输入，细节分毫不差 |
| **属性绑定 (Binding)** | 发生严重衣服/颜色/特征串色串人 | 属性归属模糊，部分特征混淆 | 大部分属性归属正确，仅微小混淆 | 每个人物的服装、发型、配饰精确绑定各自身体 |
| **动作关系 (Interaction)** | 动作完全丢失或发生主体客体颠倒 | 动作生硬或主客体关系模糊 | 动作关系基本成立，交互自然 | 动作、空间位置、视线与主谓宾关系完美呈现 |
| **总体画质 (Quality)** | 出现严重崩坏、重影或肢体错乱 | 画质一般，有局部瑕疵 | 构图良好，细节丰富完整 | 极高美感、线条与光影精致、完美二次元质感 |

## 4. 16 组典型评测用例集 (Cases)

| 用例 ID | 场景类型 | 中文输入要求 | 核心考察点 |
| :--- | :--- | :--- | :--- |
| `case_01` | 单人物 + 基础服装 | 穗穗穿着白色泳装站在沙滩上。 | 单人单属性绑定、无脑补背景 |
| `case_02` | 单人物 + 多个外貌修改 | 穗穗把金发扎成双马尾，戴着红框眼镜，穿着黑色水手服。 | 多重属性与发型/配饰/服装复合覆盖 |
| `case_03` | 两人物不同服装归属 | 穗穗穿着红色连衣裙，秧秧穿着蓝色海军水手服。 | 避免双人服装互相串色 |
| `case_04` | 两人物动作交互 | 穗穗微笑着拥抱秧秧。 | 拥抱等贴身动作的主动被动关系 |
| `case_05` | 前后追逐关系 | 穗穗在草地上追逐秧秧。 | 追赶者与被追赶者的前后空间动态 |
| `case_06` | 多人物不同道具归属 | 穗穗拿着魔法杖，秧秧拿着遮阳伞。 | 道具分别绑定到正确角色手上 |
| `case_07` | 原生角色 + 自定义角色 | 穗穗看着穿着黄色雨衣的小夏。 | 自定义角色外貌展开，名字不作 Tag |
| `case_08` | 双自定义角色区分 | 小夏把手里的冰淇淋递给小雨。 | 两个自定义角色外貌特征区分，防撞名 |
| `case_09` | 三人物群像互动 | 穗穗、秧秧和小夏一起坐在野餐垫上吃西瓜。 | 3 人场景人数与共同动作 |
| `case_10` | 复杂动作与空间关系 | 穗穗站在桥上向远处挥手，秧秧在旁边拍照。 | 两人不同位置与不同动作各司其职 |
| `case_11` | 极简稀疏 Prompt | 穗穗坐着。 | 最小输入防 AI 自由脑补背景与表情 |
| `case_12` | 画师风格注入 | 穗穗穿着华丽礼服站在星空下，画师 Mika Pikazo。 | `@mika pikazo` 画风融合度 |
| `case_13` | LoRA 触发词联动 | 穗穗穿着流动水纹裙子。 | LoRA 触发词与 Anima 渲染效果 |
| `case_14` | 动作与地点修饰绑定 | 穗穗穿着泳装，在沙滩上奔跑。 | 奔跑归属人物而非 Scene |
| `case_15` | 遮挡与视线空间关系 | 穗穗躲在树后面偷偷看着坐在长椅上的秧秧。 | 遮挡层级与视线引导 |
| `case_16` | 情绪与表情反差互动 | 穗穗气鼓鼓地转过身，秧秧在一旁无奈地笑。 | 两人不同表情与身体朝向的对比 |

## 5. 执行方式

运行批量生成：
```bash
PYTHONPATH=backend backend/.venv/bin/python backend/scripts/run_prompt_benchmark.py
```
清单将生成至 `backend/data/benchmark_results/benchmark_manifest.json`，可配合 ComfyUI 批量渲染输出各组图像并记录最终评分。
